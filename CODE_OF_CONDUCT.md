# Code of Conduct

Karis Control aims to be a welcoming, practical community for people working on self-hosted MCP tools and device management.

## Our expectations

Everyone participating in issues, pull requests, reviews, and other project spaces is expected to:

- Be respectful, considerate, and constructive, even when disagreeing.
- Critique ideas, code, and behavior rather than attacking individuals.
- Welcome contributors with different backgrounds and experience levels.
- Share enough context to make technical feedback actionable.
- Respect other people's privacy, credentials, and system boundaries.

Harassment, discriminatory remarks, threats, personal attacks, sexual harassment, unwanted disclosure of private information, and deliberate disruption are not acceptable.

## Scope

This code applies in official Karis Control project spaces and when someone represents the project publicly.

## Reporting problems

For conduct concerns, use a verified contact method listed on the [maintainer's GitHub profile](https://github.com/Karis-tlg), if available. Non-sensitive process improvements can be proposed via [pull requests](https://github.com/Karis-tlg/DesktopCommanderMCP/pulls). GitHub Issues and Discussions are currently disabled. Do not publish personal information or sensitive evidence in a public pull request.

For **software vulnerabilities or credential exposure**, follow the [Security Policy](SECURITY.md), not the general conduct process.

## Enforcement

Maintainers may moderate or remove inappropriate comments, close discussions, restrict participation, or take other proportionate actions to protect the community. Reports will be evaluated as fairly and confidentially as the available channels allow.

The goal is to keep collaboration safe, accessible, and focused on building useful software.
